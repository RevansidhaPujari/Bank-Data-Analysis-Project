# 📊 Bank Data Analysis Project

## 📌 Project Overview

This project demonstrates an end-to-end Bank Data Analysis solution developed using Microsoft Excel, SQL, Power BI, and Tableau.

The primary objective of this project is to analyze banking data, monitor key business KPIs, identify meaningful business insights, and build interactive dashboards that support data-driven decision-making.
