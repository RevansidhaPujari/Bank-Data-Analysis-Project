# 📊 Bank Data Analysis Project

## 📌 Project Overview
This project demonstrates an end-to-end Bank Data Analysis workflow using Excel, SQL, Power BI, and Tableau. The objective is to analyze banking data, identify key business insights, and build interactive dashboards for data-driven decision-making.

---

## 🛠️ Tools & Technologies
- Microsoft Excel
- SQL
- Power BI
- Tableau
